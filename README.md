# CRM MIDA

CRM comercial interno para MIDA, diseñado para centralizar clientes, contactos, oportunidades, actividades, cotizaciones, renovaciones e integraciones con los sistemas actuales de la empresa.

## Estado del proyecto

El repositorio se encuentra en su etapa inicial. El desarrollo se realizará mediante entregas verticales y Pull Requests revisables.

## Arquitectura objetivo

- Frontend: React, Vite, TypeScript y Material UI.
- Backend: .NET 8 con Clean Architecture.
- Persistencia: PostgreSQL y Entity Framework Core.
- Seguridad: JWT, roles, permisos y auditoría.
- Infraestructura local: Docker Compose.

## Primer incremento

El Sprint 0 establece la estructura base del repositorio, configuración compartida, proyectos de backend y frontend, PostgreSQL y validaciones automáticas.

## Ejecución local

Los comandos definitivos se documentarán dentro del Pull Request del Sprint 0 cuando la base técnica quede integrada.
